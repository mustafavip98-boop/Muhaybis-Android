# المحيبس — Android

مشروع Flutter أولي للعبة المحيبس العراقية.

## بناء APK من الهاتف
1. افتح تبويب Actions في GitHub.
2. اختر Build Muhaybis Android APK.
3. اضغط Run workflow.
4. بعد نجاح التشغيل نزّل artifact باسم muhaybis-android-apk.

## الحالة
هذه نسخة واجهة أولية قابلة للبناء. المجالس الحقيقية، تسجيل الدخول، قاعدة البيانات، مزامنة اللعب والصوت المباشر لم تُربط بعد. لا تعتبر هذه النسخة إصداراً أونلاين جاهزاً.
